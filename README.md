# DeepTrace

*SynoptixHackaton submission.* Live demo: https://deeptrace-vert.vercel.app

**Trace the decision. Detect the bias. Protect the candidate.**

Independent AI recruitment fairness auditing — Sprint 1 MVP, built on synthetic data.

DeepTrace examines recorded ATS screening outcomes (scores, grades, decisions), runs reproducible group-fairness tests, and gives recruitment, compliance and AI-governance teams evidence-backed audit reports. It is **read-only** with respect to any ATS, never rejects candidates or alters scores, and **never makes a legal determination of discrimination**.

> All data in this deployment is fictional and generated by DeepTrace. It is not real Workday screening results.

## Demo journey

Upload dataset → Validate → Run audit → Visualise disparity → Investigate finding → Generate report

1. **Data Hub** (`/imports`) — load the synthetic Workday-style export (325 rows, 2 requisitions) or upload a CSV; map columns to the standard schema; validate (duplicates, missing values, dates, scores); commit. Unmapped columns are dropped.
2. **Audit Lab** (`/audits/new`) — pick job, stage and an *authorised* self-reported audit category. Analysis runs server-side via `POST /api/v1/audits`.
3. **Audit results** (`/audits/[id]`) — selection rates with Wilson CIs, adverse impact ratio with CI, Fisher exact tests, Mann–Whitney score comparison, Holm correction, suppression, missingness, findings with evidence and limitations. "Re-run & verify" proves reproducibility.
4. **Investigation Centre** — assign owner, add reviewer notes, sign off a resolution (Reviewer/Admin only).
5. **Reports** — printable PDF and JSON evidence package with provenance (file + dataset SHA-256), methodology, results, findings, reviewer sign-off and a checksum.
6. **Counterfactual Lab** — matched synthetic profiles against a *mock* screening engine only.

The header role switcher (Admin / Auditor / Reviewer / Read-only) demonstrates RBAC: e.g. only Admins see raw sensitive values; Reviewers sign off; Read-only views.

## Fixture

`REQ-1042 Software Engineer`, initial screening: Male 40/100 vs Female 25/100 advanced → ratio **0.625**, Fisher p = 0.034, Holm-adjusted p = 0.068. DeepTrace flags it for investigation and explicitly notes the evidence is limited after correction.

## Architecture (this deployment)

Next.js 15 + TypeScript + Tailwind on Vercel. The fairness engine (`src/lib/fairness`) is a pure, deterministic TypeScript module with no LLM involvement; the API route `src/app/api/v1/audits` validates authorisation of the audit category, strips every field except the one analysed (data minimisation) and returns versioned results plus a dataset hash. Demo workspace state is kept in the browser (localStorage) so the public demo needs no database and holds no real personal data.

See `docs/` for the methodology and the path to the full PRD architecture (FastAPI, PostgreSQL with RLS, Celery workers, WeasyPrint, OIDC).
